## 近期（v3.0 之前）

### 1. 动物百科 · 内容层
- [ ] 生存剧本的**分段配图**：每个场景一张小场景图（复用 SVG 引擎，加 `scene` 类型）
- [ ] 支持"对比模式"：同页并排两只动物（小熊猫 vs 浣熊）
- [ ] 支持"学习包 → 笔记"一键归档到「随笔笔记」模块
- [ ] 支持"朗读剧本"（复用英语模块已有的 TTS）
- [ ] 物种别名/多语言输入（`小熊猫` / `red panda` / `Ailurus fulgens`）

### 2. 模型与提示词
- [ ] 提示词外置为 JSON（`js/agents/prompts/`），方便非程序员改文案
- [ ] 支持"思考强度"（DeepSeek V4 的 low / high / max），把 UI 选项暴露出来
- [ ] 模型能力探测：启动时请求 `/models`，把不可用的选项置灰
- [ ] 失败重试：JSON 解析失败时自动带"请只输出 JSON"再试一次

### 3. 同步与多设备
- [ ] 冲突可视化：当服务器拒绝了本地某天/某字段时，给一条可撤销的提示
- [ ] 可选"自动备份到文件"：每天导出一份 JSON 到浏览器下载目录
- [ ] 局域网内设备发现：手机扫码即可加入同一同步空间

### 4. 工程化
- [ ] 把 `check.js` 的规则拆成可单测的函数
- [ ] 增加一个"浏览器冒烟测试"（headless Chrome 打开每个 hash 路由，断言页面激活）
- [ ] 发布 Dockerfile（`python:3.12-slim` + `server.py`），一条命令跑起来

## 中期（需要设计讨论）

- **多用户/家庭**：一个空间多人共用时，需要"谁改了哪一天"的可读痕迹
- **插件式模块**：模块自注册（`XHSH.registerModule`），第三方文件可热插拔
- **数据导出格式**：兼容 Markdown / Obsidian 的导出
- **离线优先的图片**：动物百科缓存整份学习包（含 SVG）以便离线学习

---

## 长期 / 脑洞（不一定做）

- 学习曲线与推荐：根据打卡数据给"今天先做什么"
- 语音交互：口述打卡、口述复盘
- 家长视图：只读的"学习报告"页面，可分享链接
- 更多"博物"主题：植物百科、昆虫百科、星座百科（复用同一套学习包框架）

---

## 不打算做的

- 引入前端框架 / 打包工具（会破坏"改一行就能跑"的体验）
- 强制账号体系 / 云端数据库（隐私优先，同步保持可选）
- 服务端保存用户的 API Key（Key 只属于使用者）

---

## 怎么认领

1. 在 Issue 里回一句"我来做这个"，或直接开 PR 并在描述里引用本文件；
2. 不确定设计的话，先在 Discussion 里贴个方案草图；
3. 第一个 PR 不必完美 —— 能跑、能测、有说明就很好 🙌
